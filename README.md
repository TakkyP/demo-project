# Worklist — ระบบมอบหมายและตรวจเช็คงาน

เว็บสำหรับนายจ้างมอบหมายงาน และลูกจ้างถ่ายรูปส่งงานเพื่อให้นายจ้างตรวจ

**เทคโนโลยี:** Python + Flask + SQLite (ไฟล์เดียว ไม่ต้องติดตั้งฐานข้อมูลแยก) — dependency มีแค่ Flask

## การใช้งาน

| Role | แท็บที่เห็น | ทำอะไรได้ |
|---|---|---|
| นายจ้าง | รายการงาน, เพิ่มรายการ, จัดการบุคคล | สร้าง/แก้ไข/ลบงาน (ระบุบริเวณงานได้ และเลือกผู้รับผิดชอบเป็น "ทุกคน" ได้), ดูรูปที่ลูกจ้างส่ง, กด "ผ่าน" หรือ "ให้แก้ไข" พร้อมความเห็น, เพิ่ม/แก้ไข/ลบผู้ใช้ และรีเซ็ตรหัสผ่าน |
| ลูกจ้าง | รายการงาน | เห็นงานของตัวเองและงาน "ทุกคน" ที่ยังไม่มีคนรับ (กด "รับงาน" แล้วงานเป็นของคนนั้นคนเดียว), ถ่ายรูป (เปิดกล้องมือถือ) หรือเลือกรูปจากคลังภาพ แล้วกดส่งงาน |

ทุกคนเปลี่ยนรหัสผ่านตัวเองได้โดยกดที่ชื่อตัวเอง (🔑) มุมขวาบน

กด "ลบ" ที่แท็บรายการงาน = นำงานออกจากรายการเท่านั้น งานยังอยู่ใน "รายการงานทั้งหมด" (แท็บเพิ่มรายการ) และกด "นำกลับมาใช้" เพื่อเริ่มรอบใหม่ได้เรื่อยๆ ส่วน "ลบถาวร" อยู่ในตารางรายการงานทั้งหมดเท่านั้น

สถานะงาน: **รอดำเนินการ → ส่งงานแล้ว รอตรวจ → ผ่าน / ให้แก้ไข** (ถ้าให้แก้ไข ลูกจ้างส่งรูปใหม่ได้)

## ติดตั้งและรัน

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

เปิด http://localhost:5050 — ครั้งแรกระบบจะให้สร้างบัญชี **นายจ้าง** คนแรก จากนั้นเพิ่มลูกจ้างที่แท็บ "จัดการบุคคล"

ให้มือถือในวง Wi-Fi เดียวกันเข้าได้ที่ `http://<IP เครื่องนี้>:5050`

> หมายเหตุ: ปุ่ม "ถ่ายรูป" จะเปิดกล้องได้บนมือถือทุกกรณี แต่ถ้าจะใช้งานจริงผ่านอินเทอร์เน็ตควรใช้ HTTPS

## ข้อมูลเก็บที่ไหน

ทั้งหมดอยู่ในโฟลเดอร์ `data/` (สำรองข้อมูล = copy โฟลเดอร์นี้)

- `data/worklist.db` — ฐานข้อมูล SQLite (ผู้ใช้, งาน, รายการรูป)
- `data/uploads/` — ไฟล์รูป
- `data/secret.key` — กุญแจ session (สร้างอัตโนมัติ)

เปลี่ยนที่เก็บได้ด้วย env `WORKLIST_DATA=/path/to/data`, เปลี่ยน port ด้วย `PORT=8000`

## ขึ้นใช้งานจริง

```bash
.venv/bin/pip install gunicorn
.venv/bin/gunicorn -w 2 -b 0.0.0.0:5050 app:app
```

แล้ววาง reverse proxy ที่มี HTTPS ไว้ข้างหน้า (เช่น Caddy หรือ nginx) หรือ deploy บนบริการอย่าง Railway / Render / VPS ที่มี persistent disk สำหรับโฟลเดอร์ `data/`

## โครงสร้างโค้ด

```
app.py               ทุก route + ฐานข้อมูล (อ่านจากบนลงล่างตามแท็บ)
templates/           หน้าเว็บ (Jinja)
  base.html          header + แท็บ (แสดงแท็บตาม role)
  tasks.html         แท็บรายการงาน
  task_detail.html   รายละเอียดงาน / ส่งรูป (ลูกจ้าง) / ตรวจงาน (นายจ้าง)
  task_new.html      แท็บเพิ่มรายการ + ตารางงานทั้งหมด
  users.html         แท็บจัดการบุคคล
  account.html       เปลี่ยนรหัสผ่านตัวเอง
static/style.css     สไตล์ทั้งหมด
```

ลืมรหัสผ่านนายจ้างคนเดียวในระบบ: ลบไฟล์ `data/worklist.db` จะเริ่มใหม่ทั้งหมด หรือรีเซ็ตด้วยคำสั่ง

```bash
.venv/bin/python -c "import app,sqlite3;from werkzeug.security import generate_password_hash as h;c=sqlite3.connect(app.DB_PATH);c.execute('UPDATE users SET password_hash=? WHERE username=?',(h('รหัสใหม่'),'ชื่อผู้ใช้'));c.commit()"
```
